First release of **Def Jam: Fight for NY** (Xbox) statically recompiled for the **Nintendo Switch**.

**Install:** use the [installer](https://r-drg.github.io/defjam-sw-installer/) with your own copy of the game
(USA Xbox release), extract `defjam-sw.zip` into `sdmc:/switch/`, and start it from the Homebrew Menu in title
takeover mode (hold R on a game). Manual installation is in the [README](https://github.com/R-drg/defjam-sw#installing-on-the-switch).

**Works:** boot and movies, the whole front end, saves, Battle (One on One, Team, Free for All with four fighters),
Story mode with the Sketch Artist, crib, map and shops. 60 fps in one-on-one fights on the Switch.

**Files:** `defjamx.nro` (the game), `defjamx_env.txt` (settings, all optional), `LICENSES.txt`, `SHA256SUMS`.
No game data is included.

Built on [nfsu2-sw](https://github.com/antoxa2584x/nfsu2-sw) by Anton Artemov and
[xboxrecomp](https://github.com/sp00nznet/xboxrecomp) by Ned Heller — see the README's credits.
